What it does

Every line readable

The code sits beside the output. Read it, change it, run it again. Nothing hides in a service.

How it works

  1. Describe. Say what you want in your own words, in English, Spanish or Chinese.
  2. Read. The program appears as code on the right, commented and short.
  3. Run and change. Run it in the frame. Edit a line, run it again. Keep what works.

The demo writes six kinds of program plus one from your own words. It reads the words of your description to choose. This is the loop the product ships: a description becomes code you can trust, because you can read all of it.

Questions

Does this page call a model?

No. The first version runs a small engine in your browser. It picks one of six recipes by the words you write. The product's next version calls a model through our API, never from a browser key.

Does my code leave this page?

No. The page sends nothing after it loads. The program runs in a sandboxed frame with no network.

Can I keep what it writes?

Yes. Copy the code and save it as an HTML file. It runs on any browser, offline.

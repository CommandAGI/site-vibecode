如何工作

  1. 描述。 用你自己的话说明你想要什么，英文、西班牙文或中文都行。
  2. 阅读。 程序以代码的形式出现在右边，带注释，很短。
  3. 运行并修改。 在框架里运行它。改一行，再运行一次。留下有用的部分。

演示会写六种程序，再加一种用你自己的话画出来的。它读取你描述里的词来选择。这就是产品交付的循环：一段描述变成你能信任的代码，因为你可以把它全部读完。

问题

这个页面会调用模型吗？

不会。第一版在你的浏览器里运行一个小引擎，根据你写的词从六份配方里选一份。产品的下一版会通过我们的 API 调用模型，绝不在浏览器里放密钥。

我的代码会离开这个页面吗？

不会。页面加载之后不发送任何东西。程序在有沙箱、没有网络的框架里运行。

我能留下它写的东西吗？

可以。复制代码，保存成 HTML 文件。它在任何浏览器里都能离线运行。

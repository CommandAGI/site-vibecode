§8 注释

1 这个页面会调用模型吗？

不会。第一版在你的浏览器里运行一个小引擎，根据你写的词从六份配方里选一份。产品的下一版会通过我们的 API 调用模型，绝不在浏览器里放密钥。

2 我的代码会离开这个页面吗？

不会。页面加载之后不发送任何东西。程序在有沙箱、没有网络的框架里运行。

3 我能留下它写的东西吗？

可以。复制代码，保存成 HTML 文件。它在任何浏览器里都能离线运行。
